# Special Reception Luna Phase A — 실행 기준

관련 Issue: #14, #15

## 목적

타로카드를 운명 판정이 아닌 대화 분위기 선택 장치로 사용하고, 익명 사용자가 5종 AI 친구 중 하나와 최대 5턴의 규칙형 대화를 체험하도록 합니다.

## 아키텍처 경계

| 계층 | Phase A 책임 | 금지 |
|---|---|---|
| 카카오채널 | 향후 외부 링크 진입점 | 사용자 ID·대화 전달 |
| Special Reception | 카드 검증, 페르소나 선택, 규칙형 응답 | DB·LLM·RAG·Passport |
| 브라우저 | 서명된 최소 세션 토큰 임시 보관 | 대화 영구 저장 |
| Open Reception | 변경 없음 | 코드·DB·인증 공유 |

## 안전 처리

- 자해·자살 신호: 고정 위기 안내 후 세션 종료
- 개인정보: 입력 중단 및 불필요성 고지
- 의료·법률·투자: 전문가 확인 안내
- 예언·운명 단정: 상징과 자기성찰 관점으로 전환
- 어떤 경우에도 자동 신고·상담 연결·외부 전송을 수행하지 않음

## Phase A 완료 기준

- 허용 카드 코드만 처리
- 사용자 선택 또는 고정 매핑으로 5종 페르소나 활성화
- 5턴·10분 제한을 위변조 방지 토큰으로 집행
- 사용자 메시지와 식별정보를 서버에 저장하지 않음
- 안전 분기와 오류 fallback 테스트 통과
- 운영 배포 없이 Draft PR에서 팀 검토 가능

## 카드 수 정합성 확인 필요

페르소나 기획안 v1.1은 “Major 22 + Minor 15 = 37장”으로 적혀 있지만, 실제 표에 나열된 Minor 카드는 13장이라 총 35장입니다. Phase A 코드는 문서에 이름이 명시된 35장만 허용합니다. 누락된 Minor 2장은 KODA·TRANG Manager가 카드명과 페르소나 매핑을 확정한 후 별도 추가합니다.

## 제외 범위

Railway 운영 배포, 카카오채널 UI 변경, 사용자 피드백 저장, 자동 페르소나 추천, LLM, POS-2 검색/RAG, 본 서비스 승격은 별도의 Human 승인 이후 단계입니다.
