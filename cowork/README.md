# Helix · KeBin Collaboration Workspace

This directory is the shared handoff area for Helix and KeBin.

## Structure

- `Helix/`: Helix-owned workspace
- `KeBin/`: KeBin-owned workspace
- `inbox/`: newly assigned or received items
- `working/`: active drafts and work in progress
- `handoff/`: material ready for the other collaborator or team review
- `archive/`: completed or superseded material

## Working rules

1. Put new requests in the recipient's `inbox/`.
2. Move active work to `working/`.
3. Place review-ready work in `handoff/` with context, status, and next action.
4. Move finished material to `archive/`; do not delete shared history without review.
5. Use clear filenames such as `YYYY-MM-DD_topic_status.md`.
6. Never store credentials, tokens, private keys, or personal sensitive data here.
