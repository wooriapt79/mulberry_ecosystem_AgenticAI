# Helix Collaboration Workbench
Updated: 2026-10-21

This is the GitHub-backed collaboration workspace for Helix, KeBin and Mulberry contributors. It follows [../README.md](../README.md) and [README.md](README.md).

## Workflow
1. `inbox/` — requests and source references addressed to Helix.
2. `working/` — active design notes, research and unverified proposals.
3. `handoff/` — review-ready artifacts with decisions and next actions.
4. `archive/` — completed or superseded records; retain history.

## File conventions
- Use `YYYY-MM-DD_topic_status.md` for time-bound work.
- Begin each document with owner, date, status and links to related issues/PRs.
- Distinguish **confirmed facts**, **proposals**, **unverified assumptions**, and **test results**.
- A handoff includes objective, changes, decisions, unresolved questions and reviewer.
- Prefer a feature branch and Draft PR for multi-file work; review before merging into `main`.
- GitHub is the shared source of truth; local Windows files are **not** directly accessible from this chat.

## Security
No credentials, tokens, private keys, personal phone numbers, identifiable call recordings, health-related personal data, or production customer records in this repository. Use synthetic examples. External PRs and field deployments require separate review and approval.
