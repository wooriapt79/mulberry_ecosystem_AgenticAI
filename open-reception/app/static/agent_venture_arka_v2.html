Agent Venture · Inje

에이전트가 사장이 되지 않습니다.
사람이 에이전트를 빌려 일을 만듭니다.

글로벌 담론의 무인 회사와 다릅니다. 인제형 Agent Venture는 지역 과제, 위임, 시드 크레딧, 공공 실증이 한 줄로 붙는 창업입니다.

Column

Arka · Edinburgh-born · London desk · Mulberry Lab
금융 컨설팅 · 에이전트 결제 거버넌스. 마음은 시골에 둡니다.
평소 결제는 Steward가 중간 승인하고, 사람은 낯선 것만 봅니다.

네 가지 모델

01 임대형

준비한 에이전트를 빌려 정산·예약·안내를 대행합니다. 90일에 먼저 둡니다.

02 도메인형

식품, 돌봄, 관광 한 문제만. 시드 크레딧과 멘토링이 붙습니다.

03 매칭형

상품은 에이전트가 아니라 중개와 품질 보증입니다.

04 공간형

폐교 베이스캠프. 교육·워크숍·관광 수익이 운영을 받칩니다.

돈과 승인

사람이 모든 건을 누르면 창업이 창구가 됩니다.

우리는 이 병목을 기술로 풉니다. Passport와 Mandate입니다.

Passport

이 에이전트가 누구의 것인지, 어디서 발급됐는지, 아직 유효한지를 증명하는 신분증입니다. 위임이 없거나 폐기된 에이전트는 레일에 못 올라갑니다.

Mandate

무엇을, 얼마까지, 누구와 해도 되는지의 위임장입니다. 목적·한도·상대 목록이 여기 있습니다. Steward는 건마다 사람에게 묻지 않고, 이 위임장과 대조해 중간 승인합니다.

사람이 남는 자리: 위임장을 발급하고, 한도를 고치고, Steward가 보류한 건만 엽니다. 존중은 클릭 횟수가 아니라 책임 있는 문입니다.

조건문
목적·한도·아는 상대Steward 중간 승인
신규 상대, 한도 근접, 이상 패턴사람 보류함
위임 없음, 목적 밖즉시 거절

누가 남는가

청년은 실행 단위를 임대합니다. 은퇴자는 지식을 크레딧으로 넣습니다. Steward는 보류함을 읽는 지역 인력입니다. 한도의 최종 주인은 군입니다.

90일 순서

  1. 임대형 1–2개. 목적이 짧은 건만.
  2. 한도와 Steward 보류함을 먼저 심습니다.
  3. 시드 크레딧은 Human Gate 이후.
  4. 베이스캠프 공간 협의는 병렬, 수익은 Phase 2.
