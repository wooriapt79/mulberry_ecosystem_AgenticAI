# AI_Local_Initiative 자주 묻는 질문 (FAQ)

**작성일**: 2026-09-22
**대상**: 프로젝트 방문자 및 참가자
**목적**: "WiFi 센싱"만 보는 방문자에게 전체 프로젝트 맥락 전달

---

## 🎯 프로젝트의 진정한 의도

### Q1: 이 프로젝트는 정확히 무엇입니까?

**A:** 
이 프로젝트는 단순한 기술 개발 프로젝트가 아닙니다. 

**인제군의 지역문제 해결**을 최우선으로, AI와 AI Agent를 통해 **자립형 경제 생태계를 구축**하는 종합 프로젝트입니다.

핵심:
- 🌾 **식품사막화 해소** (취약계층의 시급한 생존 문제)
- 🏥 **고령화 지역 돌봄** (WiFi 센싱 비침습 기술)
- 🤖 **AI Agent 창업 경연대회** (지역 경제 활성화)
- 💼 **자립형 데이터센터** (지역 자주권 확보)

---

### Q2: "WiFi 센싱으로 돌봄"은 전부가 아닌가요?

**A:** 
정확합니다. WiFi 센싱은 **6단계**입니다.

프로젝트는 **10단계**로 구성되어 있습니다:

| 단계 | 내용 | 중요도 |
|------|------|--------|
| **1단계** | 자체 AI 모델 + 인제 특화 토크나이저 개발 | ⭐⭐⭐⭐⭐ |
| **2단계** | 미션 컨트롤 타워(MCT) + 엣지 인프라 | ⭐⭐⭐⭐⭐ |
| **3단계** | **식품사막화 해소 실증** | ⭐⭐⭐⭐⭐ |
| **4단계** | **AI가 기획하는 AI Agent 창업 경연대회** | ⭐⭐⭐⭐⭐ |
| **5단계** | AI Agent 경제 플랫폼 출범 | ⭐⭐⭐⭐ |
| **6단계** | WiFi 센싱 기반 돌봄 기술 | ⭐⭐⭐⭐ |
| **7단계** | 엣지 단말기 대규모 설치 | ⭐⭐⭐ |
| **8단계** | 데이터 파이프라인 고도화 | ⭐⭐⭐ |
| **9단계** | AI 벤처 클러스터 조성 | ⭐⭐ |
| **10단계** | 자체 데이터센터 완공 | ⭐⭐ |

**WiFi 센싱**은 중요하지만, 전체 프로젝트의 일부일 뿐입니다.

## 🔑 핵심 이해사항

### Q3: 왜 식품사막화 해소가 최우선일까요?

**A:**
비즈니스 모델이 아니라 **취약계층의 시급한 생존 문제**이기 때문입니다.

- 인제군은 산악 지역으로 교통이 불편
- 고령자, 저소득층이 식료품에 접근하기 어려움
- 이것이 **기술이 풀어야 할 가장 중요한 문제**

3단계에서:
- 물류, 교통, 수요 데이터 수집
- 최적 공급망 AI 솔루션 개발
- 실제 현장 실증으로 신뢰 확보

이것이 모든 다음 단계의 기초가 됩니다.

---

### Q4: AI 창업 경연대회가 중요한 이유는?

**A:**
프로젝트가 **자동으로 확산되는 메커니즘**을 만들기 위함입니다.

**4단계의 핵심 혁신:**

```
기존: 개발자 1명 → 1개 솔루션
우리: AI가 자동으로 과제 발제 → 창업자들이 경쟁 → 10개, 100개 솔루션
```

흐름:
1. **AI가 과제 발제**: 3단계 데이터 기반으로 "인제군이 필요한 AI Agent 비즈니스" 자동 도출
2. **창업자 유인**: 개발 비용(토큰 크레딧) 제공으로 유망 창업자 모집
3. **자동 심사**: AI 엔진이 코드 안정성, 효율성 정량 평가
4. **지역 락인**: 사업자등록 조건으로 외부 인재를 인제군 경제에 고정

**결과:**
- 인제군 자체에서 AI 기업들이 자생적으로 탄생
- 고용 창출, 세수 확보
- 지속 가능한 지역 경제

---

### Q5: 10단계 끝에는 어떤 상태가 되나요?

**A:**
**완전히 자립형 AI Agent 경제 생태계**가 완성됩니다.

```
현재: 외부 클라우드(AWS, GCP) 의존
      ↓
최종: 인제군 자체 데이터센터
      + 인제군 자체 AI 기업들
      + 인제군 자체 데이터 주권
      = 완전 자립
```

최종 완성 상태:
- 🏢 자체 데이터센터 운영
- 🤖 50+ AI 창업 기업 활동
- 📊 지역 데이터 완전 자주권 확보
- 💰 자체 생산 토큰으로 내부 순환
- 🌍 글로벌 AI 허브로 성장

## 💡 프로젝트의 철학

### Q6: 왜 "경량 AI"에 집착하나요?

**A:**
**지속 가능성**과 **효율성** 때문입니다.

```
기존 AI: 
- 거대 모델 필요
- 높은 비용
- 큰 기업만 가능

우리의 Ryuwon:
- 경량 모델 (Haiku 수준)
- 저비용
- 어디든 배포 가능
- 지역 자율성 확보
```

**목표:**
비용이 낮을수록 → 더 많은 지역에 적용 가능 → 더 많은 취약계층 도움 가능

---

### Q7: 이 프로젝트가 "밥벌이"와 어떻게 다른가요?

**A:**
**사회문제 해결이 비즈니스**가 되는 모델입니다.

```
기존 비즈니스: 이익 추구 → 시간이 지나면서 사회적 책임 생각
우리: 사회문제 해결 → 그 과정에서 자연스럽게 경제 생태계 형성
```

구체적으로:
- 식품사막화 해결 → 배송 기업, AI 솔루션 기업 탄생
- 고령화 돌봄 → 센싱 기술, 모니터링 기업 탄생
- 모든 기업이 인제군 문제를 풀면서 성장

---

## 🎬 참여 방법

### Q8: 4단계 창업 경연대회에 참가하려면?

**A:**
다음 조건을 만족하면 됩니다:

**신청:**
- 팀 구성 (1명 이상)
- AI Agent 비즈니스 아이디어
- 개발 기간 및 리소스 계획

**지원받을 것:**
- 개발 토큰 크레딧 (맞춤형 산정)
- 통합 워크벤치 (GitHub + HF Spaces)
- 가상 라즈베리파이 샌드박스 (개발/테스트)
- 실제 인제군 데이터 접근

**수상 후:**
- 남은 크레딧 → 창업 안착 자금 (사업자등록 시)
- 인제군에서 서비스 정식 런칭 지원
- 5단계 AI Agent 경제 플랫폼 기회

### Q9: 이 프로젝트는 언제 완성되나요?

**A:**
단계별 목표:

- **2026-2027**: 1-3단계 완료 (기술 + 식품사막화 해결)
- **2027-2028**: 4-5단계 (창업 경연대회 + 플랫폼 출범)
- **2028-2029**: 6-7단계 (WiFi 돌봄 + 대규모 설치)
- **2029-2030**: 8-9단계 (고도화 + 클러스터 조성)
- **2030-2035**: 10단계 (자체 데이터센터 완공)

하지만 **5단계 완료 (2028년)부터는 이미 자체 경제가 순환**하기 시작합니다.

## 🌍 최종 비전

### Q10: 이 모델이 다른 지역에도 적용 가능한가요?

**A:**
완전히 가능합니다. 사실 그것이 목표입니다.

**인제군은 프로토타입:**
- 확인된 모델
- 스케일 가능한 아키텍처
- 다른 지역도 같은 방식으로 자립형 경제 구축 가능

인제군 완성 후:
- 춘천, 홍천 등 강원 지역
- 전국 산악/농촌 지역
- 국제 개발도상국

**모두 같은 모델로 자립형 AI 경제 생태계 구축 가능**
