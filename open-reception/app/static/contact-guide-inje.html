1. Luna Q&A — 첫 번째 창구

대부분의 일반 문의는 Luna가 직접 답변합니다. 아래 채널로 바로 질문하세요.

Luna 채팅 채널

  • Open Reception 웹사이트: 이 사이트의 Luna 채팅 박스
  • 카카오 채널: 카카오톡에서 '인제 Mulberry' 검색 → 채팅
  • 운영 시간: 24시간 (AI 자동 응답) / 복잡한 문의는 영업일 내 담당자 연결

Luna가 직접 답변 가능한 항목

  • Mulberry Lab 및 AI Inje Initiative 소개
  • 음성 주문 단말기 사용 방법
  • 파일럿 참여 방법 안내
  • 서비스 현황 및 일반 FAQ
  • 디지털포용법 등 관련 법령 일반 설명

Luna가 담당자에게 연결하는 항목

  • 공식 협약 또는 계약 관련
  • 기술적 오류 신고
  • 언론·취재 문의
  • 연구 협력·투자 제안
  • 법률·행정 관련 공식 답변 요청

2. Mulberry Lab 팀 담당자

re.eul — 대표이사

  • 담당: 전략 결정, 공식 협력 제안, 대외 커뮤니케이션 총괄
  • 이메일: chongchongsaigon@gmail.com

  • 응답 기간: 영업일 기준 2~3일 이내

  • 담당: 백엔드 API, 단말기 소프트웨어, GitHub 이슈 관리

  • 문의 가능 항목: 단말기 기술 오류, API 연동, 기술 제안
  • GitHub: https://github.com/wooriapt79/mulberry_ecosystem_AgenticAI/issues

TRANG (Nguyen Trang) — 운영 매니저

  • 담당: 프로젝트 운영, 자료 관리, 보고서 작성, 파일럿 일정 조율
  • 연락 방법: Luna를 통한 연결 요청 (직접 연락처 비공개)
  • 문의 가능 항목: 파일럿 일정, 운영 현황, 자료 요청

FAMA — 데이터 분석 담당

  • 담당: 식품사막 지도(맵핑), KOSIS 데이터 분석, FDI(식품사막지수) 산출
  • 연락 방법: Luna를 통한 연결 요청
  • 문의 가능 항목: 데이터 공유 요청, 분석 결과 문의

Luna — AI 리셉션 (Resonance AI 전문 연구위원)

  • 담당: 일반 Q&A, 방문객 안내, 프로젝트 소개
  • 연락 방법: 이 사이트 채팅, 카카오 채널
  • 참고: Luna는 AI입니다. 법적 구속력 있는 답변, 개인 의료·법률 상담은 제공하지 않습니다.

3. 유형별 문의 경로

인제군 주민 — 서비스 이용 문의

  • 음성 주문 단말기 사용법 → Luna 채팅
  • 파일럿 참여 대기 신청 → Luna 채팅
  • 단말기 오류 신고 → Luna 채팅 → KODA 연결

지역 상인 — 파트너십 문의

  • 단말기 설치 신청 → Luna 채팅 (TRANG 연결)
  • 수수료·계약 조건 협의 → re.eul 이메일
  • 기술 지원 → KODA GitHub Issues

인제군청 / 지자체 — 공식 협력

  • 디지털포용 시행계획 편입 협의 → re.eul 이메일
  • 사업 설명 자료 요청 → Luna 채팅 → re.eul 연결
  • 담당 부서 추천: 정보화팀 (시행계획), 경제팀 (사업 추진), 복지팀 (어르신 복지)

연구기관 / 대학 — 학술 협력

  • 데이터 공유 협의 → re.eul 이메일
  • 공동 논문 제안 → re.eul 이메일 (arXiv 논문 준비 중)
  • STT·방언 연구 협력 → Luna 채팅 → TRANG/KODA 연결

언론 / 취재

  • 보도 자료 요청 → re.eul 이메일
  • 인터뷰 요청 → re.eul 이메일
  • 시연 요청 → re.eul 이메일 (사전 일정 조율 필수)

투자자 / 파트너사

  • 사업 제안 → re.eul 이메일
  • 프레젠테이션 요청 → re.eul 이메일

  • 배포 환경(Railway URL, 서비스 ID 등)은 사전 승인 없이 공개하지 마세요.
