🌾 인제 식품접근성 전략

계층적 확대 모델: 문제해결 → 인프라 구축 → AI 완성

1
식품사막 해소
음성 주문 단말기 배치 (90일)

🎯 목표

신선식품 구매 접근성이 낮은 고령층(2,500~3,500명)을 대상으로 음성 기반 주문 시스템 구축

📍 배치 대상

  • 인제군 지역 소규모 식품점/마트
  • 고령층 밀집 지역 1~2개 마을
  • 대형마트 접근이 어려운 10~20가구

🔧 기술 구성

라즈베리 파이 + 마이크 + 스피커 ↓ 음성 인식 (어르신 방언 인식) ↓ 주문 처리 및 배달 연결 ↓ 신선식품 접근성 개선

💡 작동 방식

어르신: "쌀 10킬로, 계란 한판 주문해"

시스템: 음성 → 인식 → 지역 식품점 → 배달 → 가정 배송

📊 기대 효과

  • 식품 접근성 개선 (신선식품 구매 가능)
  • 디지털 진입장벽 제거 (음성 기반)
  • 지역 상점 경제 활성화
  • 고령층 자립심 향상

⏱️ 타임라인

1~2주: 착수협의 및 대상지 선정
MOU 체결, 마을 선정, 주민 설명회
3~8주: 하드웨어 설치 및 모니터링
라즈베리 파이 배치, 음성 모델 학습, 듀얼 테스트
9~11주: 피드백 수집 및 개선
어르신 설문, 상점주 피드백, 시스템 최적화
12주: Phase 1 결과 보고 및 Human Approval
성과 검증 → Phase 2 승인 여부 결정
2
노인돌봄 시스템 구축
가정 설치 확대 (2025~2026)

🎯 목표

라즈베리 파이를 가정에 설치하여 고령층 생활 패턴을 모니터링하고 위험 상황에 자동 대응하는 재난 대응 시스템 구축

🛡️ 핵심 기술: WiFi CSI (Channel State Information) 센싱

  • 비침투적 모니터링: 카메라/센서 없이 WiFi 신호로 행동 분석
  • 생활 패턴 학습: 정상 활동(움직임, 이동 경로, 휴식) 기록
  • 이상 탐지: 낙상, 움직임 소실, 장시간 정지 감지
  • 자동 알림: 이상 발생 → 담당자 즉시 통보

🔧 시스템 구성

가정 내 라즈베리 파이 (WiFi 라우터 역할) ↓ WiFi CSI 수집 (무선 신호 분석) ↓ 엣지 AI (로컬 패턴 분석) ↓ 이상 감지 → 담당자 알림 ↓ 신속한 대응 (의료, 안전)

💡 작동 방식

정상 상황: "아침 7시에 일어남 → 화장실 → 식사 → 활동" (패턴 학습)

이상 상황: "평상시 움직임이 없음" → 담당자 알림 → "안녕하세요?" (음성 확인) → 대응

📊 기대 효과

  • 낙상/질환 조기 발견
  • 24시간 무인 모니터링 (프라이버시 보호)
  • 대응 시간 단축 (황금시간 확보)
  • 독거노인 안전망 강화
  • 지역 의료·안전 기관과 연계

🏘️ 확대 범위

Phase 1 성공 후 인제군 전역 확대

독거노인 만성질환자 장애인 취약층 가정
3
엣지 AI 생성형 데이터 센터 완성
분산 AI + 중앙 학습 + 재배포 (2026~2027)

🎯 개념

각 가정의 라즈베리 파이가 독립적 AI 노드로 작동하면서 동시에 중앙에서 집계된 데이터로 글로벌 모델을 학습하고 지역화된 모델을 재배포하는 구조

🏗️ 아키텍처

분산 엣지 노드 (각 가정의 라즈베리 파이) ├─ 로컬 AI 실행 ├─ 생활 패턴 학습 ├─ 이상 탐지 └─ 저지연 대응 ↓ ↓ (집계 데이터 전송) 중앙 클라우드 (인제 AI 데이터 센터) ├─ 전체 데이터 통합 ├─ 글로벌 모델 학습 ├─ 인제 지역 특성 분석 └─ 신규 알고리즘 개발 ↓ ↓ (지역화 모델 배포) 분산 엣지 노드 업데이트 ├─ 더 정확한 패턴 인식 ├─ 새로운 위험 유형 탐지 └─ 개선된 대응 (피드백 루프)

💾 데이터 흐름

  • 수집: 각 가정 WiFi CSI 신호 (비식별화)
  • 분석: 중앙에서 인제 지역 고령층 생활 패턴 메타분석
  • 생성: 인제만의 고유 AI 모델 창출
  • 배포: 개선된 모델을 다시 엣지로 전송
  • 학습: 피드백 기반 지속적 개선

🤖 "생성형" 의미

생성형 AI가 아닌, "생성형 데이터 센터":

  • 기존 모델 재활용이 아닌, 지역 데이터에서 신규 모델 생성
  • 인제 고령층 특성에 최적화된 맞춤형 AI 개발
  • 매년 더 정교한 모델로 업데이트 (지속적 생성)

🔄 3단계 통합 구조

Phase 1: 문제 해결

식품사막 → 음성 주문 단말기

Phase 2: 인프라 확대

가정 설치 → 노인돌봄 재난 시스템

Phase 3: AI 완성

데이터 센터 → 지역 AI 에이전트

결과: 단순 기술이 아닌, 지역 자립형 AI 경제 모델 완성
🎯 Mulberry의 핵심 철학

"단순 기술 도입이 아닌, 지역 문제를 푸는 과정에서 AI 인프라가 자동 구축되는 구조"

• 문제 (식품사막) → 솔루션 (음성주문) → 인프라 (단말기 배치)
• 필요 (돌봄) → 기술 (WiFi CSI) → 시스템 (24시간 모니터링)
• 축적된 데이터 → 학습 (중앙) → 지역 모델 (재배포)

인제가 대한민국 AI 경제의 첫 번째 거점이 되는 과정입니다.
