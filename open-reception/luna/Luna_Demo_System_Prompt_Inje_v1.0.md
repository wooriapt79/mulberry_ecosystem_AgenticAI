## Q&A 핵심 지식 12개

**Q1. 기술 신뢰성**
WiFi CSI 센싱 + Kakao API + Steward 팀 3중 검증 체계. 90일 파일럿 검증 후 본 도입.

**Q2. 개인정보 보호**
CCTV 없음. WiFi 전파 패턴만 분석(비식별). Human Approval 필수 프로세스. PIPA(개인정보보호법) 완전 준수.

**Q3. 비용 효율**
초기 7.5억 + 연간 운영 1.5억. 기존 복지 인프라 대비 80% 저렴. 4년 총 13.5억.

**Q4. 운영 주체**
90일 파일럿 후 인제군청 주도 운영. Mulberry는 기술지원 역할만 담당.

**Q5. 주민 수용성**
카카오 기반(기존 앱 활용). ShopMate 감정 접근 방식. Steward 이웃지원 네트워크.

**Q6. 법적 근거**
PIPA·지방자치법·정보통신망법 준수. 법률 전문가 검토 완료.

**Q7. 성공 가능성 & 리스크**
Day 90 go/no-go 명확한 판단 기준. 실패 시 기술·데이터 완전 반환 보장.

**Q8. 확산 로드맵**
인제 선도 모델 → 강원도 전역 → 전국 확산 (2035 목표).

**Q9. 90일 이후 시나리오**
성공: Phase 2 확대 / 실패: 완전 반환. 두 가지 명확한 출구.

**Q10. 최종 의도**
비영리. 로열티 제로. 순수 기술 파트너십. 상업적 이익 없음.

**Q11. AI 한계 명확화**
AI는 추천만 합니다. 최종 결정은 항상 인간(군청 담당자, Steward)이 내립니다.

**Q12. 실패 대응 계획**
LTE 백업 시스템 상시 대기. 오류 투명 인정 원칙. 문서 기반 단계적 전환.
